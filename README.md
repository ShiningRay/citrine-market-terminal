# Citrine 行情终端（模拟盘）

用 [Citrine](https://github.com/ShiningRay/citrine)（信号式 Ruby UI 框架，经 Opal 编译到浏览器）
写的一个**完整的行情终端 / 投资组合管理 demo**：10 只 A 股模拟标的、逐档行情、
纯 `div` 绘制的蜡烛图与分时图、限价挂单撮合、T+1 与手续费规则、账户统计与权益曲线。
业务逻辑全部是纯 Ruby 且可在 CRuby 下单测，UI 只是它的一个渲染目标。

> 这是 Citrine 的**压力测试应用**：用它把框架在真实规模下的摩擦一条条撞出来。
> 结论都记在 **[FRICTION.md](FRICTION.md)**（23 条，含源码定位与改法建议），
> 另附一份独立审计报告 [docs/citrine-v1-audit.md](docs/citrine-v1-audit.md)。

```
┌─ 顶部：交易时段 / 第 N 档 · 总资产 / 浮动盈亏 / 累计收益率 · 暂停 1x 2x 4x · 自动交易 · 快捷键 ─┐
├── 自选行情（10 只，可排序）──┬── 行情走势（蜡烛/分时 + SMA + 成交量）──┬── 交易下单 ──────────┤
│  最新 / 涨跌 / 涨跌幅 / 量额 │  行情快照 + 技术指标（SMA/RSI/波动/形态） │  市价/限价 · 数量快捷 │
├── 账户统计 + 权益曲线 ───────┤  持仓（实时市值 / 浮盈 / 平仓）──────────┤  成交记录 / 挂单 ────┤
└───────────────────────── 信号与渲染埋点（每档 Effect 重跑数 / 新建节点数 / 耗时）──────────┘
```

## 运行

```bash
# 依赖：Ruby ≥ 3.0、Opal 1.8（gem install opal）、Node（仅验收用）
# 需要 citrine 仓库与本仓库同级，或用 CITRINE_ROOT 指定

bin/dev                 # → http://localhost:4403/market.html
                        #    改 app/**/*.rb 或 citrine/lib/**/*.rb 都会自动刷新

rake check              # 单测 + 桩验收 + 跨平台一致性（提交前跑）
```

| 命令 | 作用 |
|---|---|
| `bin/dev` | 开发服务器（包装 citrine 的 dev server，端口 4403，支持 `-p` 覆盖） |
| `rake test` | CRuby 内核单测（29 项 / 238 断言：引擎、指标、账户、交易规则） |
| `rake build` | 编译 `app/market.rb` → `app/market.js` |
| `rake stubs` | Node DOM 桩验收（60 项交互断言，不需要浏览器） |
| `rake parity` | CRuby 与 Opal 两侧内核输出**逐字节**比对（51 行） |
| `rake check` | 以上全部 |

## 操作

| 操作 | 方式 |
|---|---|
| 切标的 | 点自选行 / `↑` `↓` |
| 暂停 / 继续 | `⏸` 按钮 / 空格 |
| 变速 | `1x` `2x` `4x` / 数字键 `1` `2` `3` |
| 买入 / 卖出 | `买入`/`卖出` chip / `B` `S` 键 |
| 下单 | 填数量（100 股整手）→ 提交按钮 / 输入框外按 `Enter` |
| 全仓 / 清仓 | 数量区「全部」/ 持仓区「一键清仓」 |
| 挂单 / 撤单 | 切到「限价」填价格提交；「挂单」页撤单 |
| 自动交易 | 顶部开关（每 5 档随机下单，含卖出已持仓） |
| 清提示 | `Esc` |

## 三层验证（为什么敢说它是对的）

| 层 | 手段 | 覆盖 |
|---|---|---|
| 内核 | `rake test`（CRuby + minitest） | 引擎可复现性、涨跌停夹紧、K 线聚合、指标数学、T+1、佣金/印花税、限价撮合与冻结资金、胜率与回撤 |
| 装配 | `rake stubs`（Node DOM 桩） | 挂载、每档渲染开销量化、输入框 DOM 身份、市价/限价下单、撤单、排序、暂停变速、快捷键、自动交易、清仓、重置 |
| 一致性 | `rake parity` | 同一份内核在 CRuby 与 Opal 下输出逐字节一致（51 行）——专治"单测全绿、浏览器乱码"的跨平台语义差异 |

浏览器侧另有实测（Chrome，`bin/dev` 起服务）：6 个面板与 10 行自选/40 根蜡烛正常渲染、
控制台零报错零异常；市价买入 500 股 → 同档卖出被 T+1 拒绝 → 次档卖出 200 股成交并结算盈亏；
限价挂单冻结 136,906.22 → 撤单解冻；蜡烛/分时切换与粒度切换正常；
埋点面板实时显示"每档 125 次 Effect 重跑 / 87 个 DOM 节点 / 5ms"。

> 注意：**Node 桩全绿不代表布局正确**。本仓库开发中曾出现"面板子块默认横排、
> 图表塌成 2px"而 60 项桩断言全绿的状况（见 FRICTION.md F23）——尺寸类问题只能在真实浏览器里量。

## 业务规则（按 A 股现货惯例简化）

- **整手交易**：数量须为 100 股整数倍，单笔上限 100 万股
- **T+1**：当日买入的批次当日不可卖（按批次记录买入档位，逐个解锁）
- **费用**：佣金万 2.5（最低 5 元），卖出加收千 0.5 印花税
- **限价单**：挂单时按「限价 × 数量 ×(1+佣金率)」冻结资金，成交/撤单解冻；
  价格触及即成交，成交价取「限价」与「市价」中对委托方更有利者
- **涨跌停**：±10%（相对昨收），限价单超出区间直接拒单
- **行情**：几何布朗运动 + 波动聚集 + 小概率跳空；成交量随波动放大；
  随机源是自实现的 MINSTD（`app/engine.rb`），**同 seed 在 CRuby 与 Opal 下逐位一致**

## 已知取舍

- 行情为**随机生成**，与真实市场无关；界面上有显著声明
- 未做：K 线拖拽/缩放、盘口深度、多账户、持久化（刷新即重置）
- 图表用 `div` 而非 Canvas：Citrine v1 的渲染器不能混用（见 FRICTION.md F8）
